# Call of Pripyat VR — Альфа 0.1.0

Неофіційний безкоштовний PC VR мод для **оригінальної Steam S.T.A.L.K.E.R.: Call of Pripyat 1.6.02**, створений на основі OpenXRay. Потрібна придбана оригінальна гра; її архівів у пакеті немає. Власник підтвердив роботу установки й запуску 2026-10-25; регресійна перевірка окремих функцій ще не завершена. Мод не є офіційним продуктом GSC Game World, Valve або Meta.

## Вимоги та межі підтримки

- Windows 10/11 x64, .NET Framework 4.8 для інсталятора й лаунчера, DX11-сумісна відеокарта та робоче 64-бітне середовище OpenXR. Для запуску через EXE не потрібні Python, Visual Studio чи налаштування PowerShell.
- Перевірялася **Meta Quest 2, контролери Touch, USB Quest Link**. Інші гарнітури, Air Link, Steam Link, Virtual Desktop, середовище SteamVR та гра сидячи не перевірені. Відстеження голих рук не реалізоване.
- Підтримується оригінальна класична Steam-версія. Enhanced Edition, Anomaly, глобальні модифікації та мережевий режим цією альфою не підтримуються. Повного проходження кампанії ще не було.
- Мінімальні вимоги до GPU та гарантований FPS не визначені. На комп’ютері розробки використовується RX 6900 XT; це не заявлений мінімум.

## Встановлення та запуск

1. Встановіть оригінальну гру зі Steam, один раз перевірте звичайний запуск і закрийте її.
2. Відкрийте Meta Quest Link на ПК, виберіть його активним середовищем OpenXR, під’єднайте гарнітуру через USB та увійдіть у Quest Link.
3. Запустіть `CoPVR-0.1.0-alpha.1-Setup.exe`. Перевірте знайдену папку гри або вкажіть її вручну. Для мода виберіть **окрему порожню папку за межами папки гри**. У цій альфі обидва шляхи мають містити тільки латиницю/ASCII. У папці з доступом на запис права адміністратора не потрібні.
4. Відкрийте ярлик або `CoPVR.exe`, натисніть **Запустити у VR**. Інсталятор сам гру не запускає.
5. У грі станьте рівно, подивіться в бажаний напрямок уперед і **натисніть правий стік**. Це калібрує початок відліку кімнати, напрямок, висоту очей і колайдер стоячого персонажа. У присяді калібрування заблоковане. Перед входом у гру відпустіть курки та відцентруйте стіки.
6. Для перевірки почніть нову гру. Старі збереження можна вручну скопіювати до `data/savedgames`, попередньо зробивши резервну копію. Не замінюйте оригінальні збереження VR-версіями: штатний рушій не гарантовано прочитає додаткові стани зброї.

Альтернатива — portable ZIP: розпакуйте в нову папку з доступом на запис, відкрийте `CoPVR.exe`, виберіть **Змінити папку гри**, потім запускайте. Portable-варіант не реєструє деінсталятор і не створює ярлик.

Оригінальні архіви залишаються у Steam-папці. Власні налаштування, збереження, журнали, скріншоти й кеш мода знаходяться в `data/`. Звичайний запуск зі Steam залишається окремим. Для видалення встановленої версії закрийте гру й лаунчер та скористайтеся списком програм Windows або `Uninstall.ps1`; папка `data/` зберігається. Для portable збережіть `data/` та вручну видаліть розпаковану папку.

## Назви кнопок

**Grip** — бічний/нижній курок під середнім пальцем. **Тригер** — передній/верхній курок під вказівним пальцем; у попередніх обговореннях він також називався бампером. Для нового захоплення потрібне нове натискання grip. Прохід крізь зону з уже зайнятою рукою не повинен міняти предмет. Точка взаємодії — долоня.

| Кнопка або рух | Дія |
|---|---|
| Лівий стік | Рух відносно напрямку погляду |
| Натискання лівого стіка | Спринт; у фізичному присяді недоступний |
| Правий стік ліворуч/праворуч | Поворот кроками по 30° |
| Правий стік униз | Наступний доступний режим вогню поточної зброї; це вже не прибирання зброї |
| Правий стік угору/вниз під час використання бінокля | Збільшення бінокля |
| Правий стік угору/вниз у меню | Прокручування |
| Натискання правого стіка | Калібрування стоячи |
| A | Стрибок |
| X | Інвентар |
| B | PDA |
| Y / кнопка меню лівого Touch | Назад / головне меню |
| Grip | Взяти, утримувати предмет або дістати спорядження із зони |
| Тригер зі зброєю | Постріл |
| Тригер із предметом | Застосувати предмет, якщо дія підтримується |
| Тригер порожньою рукою | Навести руку на ціль та виконати дію F: діалог, двері, перемикач, сон тощо |

Клавіатура та миша у VR не керують грою. У меню використовуйте промінь Touch і тригер. На клавіатурну комбінацію як спосіб відновлення завислого меню покладатися не слід; засоби Windows поза грою доступні. Не всі вікна введення тексту й рідкісні штатні меню перевірені.

## Зони на тілі

Повна модель персонажа та старий пояс із предметами приховані. Зони спираються на оцінене положення тулуба, обмежено слідкують за головою й вирівнюються за рухом. Реальних трекерів таза/тулуба немає.

| Де знаходиться рука | Дія |
|---|---|
| За головою / біля задньої частини голови | Нове натискання grip дістає зброю з відповідного штатного слота: ліва рука — лівий слот, права — правий. Відпускання зброї в зоні кобури біля голови миттєво прибирає її зі звуком. Тип зброї у слоті не прив’язаний до пістолета чи гвинтівки. |
| Біля лівої або правої скроні, близько до гарнітури | Короткий grip із відпусканням перемикає ліхтарик. Утримання приблизно 0,65 с перемикає ПНБ, якщо спорядження його має; ліхтарик при цьому додатково не перемикається. |
| Верхня частина грудей | Лівий grip — детектор, правий — бінокль. Відпускання повертає спорядження. Штатні обмеження сумісного спорядження збережено, крім окремих дозволених поєднань із детектором/болтом. |
| Груди, grip + тригер | Дістати активовану гранату. Кидок — рух руки й відпускання grip. Відпускання всередині зони грудей скасовує активацію та повертає гранату. Не натискайте цю комбінацію випадково. |
| Дві сусідні зони під грудьми | Ліва рука: ліва зона — хотбар 1, права — 2. Права рука: ліва зона — хотбар 3, права — 4. Предмети призначаються в інвентарі. |
| За поясом | Лівий grip зазвичай дістає ніж, правий — болт. З активною вогнепальною зброєю вільна рука за поясом може дістати допоміжний болт. Діставання ножа у конфліктному випадку зі зброєю в правій руці заблоковане. |
| За поясом вільною рукою, grip + тригер | Дістати предмет для перезаряджання зброї в іншій руці: магазин, патрон, ракету або гранату для гранатомета. Це спеціальний активатор, а не звичайна коробка набоїв. |
| Зона складання на грудях | Відпустити придатний предмет зі світу/інвентаря для перенесення в інвентар. Використовується та сама область, що й для нагрудного спорядження. |

Для пошуку зон увімкніть **Налаштування → Гра → VR: зони взаємодій** та натисніть «Застосувати». Вибір зберігається. За замовчуванням контури вимкнені; вони показують об’єм активації, а не фізичну поверхню. Якщо жест не спрацьовує, спершу відпустіть обидва курки й повторіть порожньою рукою: деякі фізичні дії мають вищий пріоритет.

## Предмети, інвентар, PDA

- Для утримання тримайте grip. Відпускання кидає/випускає предмет, якщо не діє правило складання чи повернення. Ніж, бінокль і детектор повертаються як спорядження; болт кидається, новий стає доступним після кидка.
- Зброя зі світу екіпірується, якщо взяти її за рукоятку. Можна передавати між руками. Справжнє захоплення цівки другою рукою стабілізує наведення та підвищує точність.
- Предмети можна піднімати, оглядати, передавати та кидати. Захоплення ящиків, тіл та інших фізичних об’єктів експериментальне. Утримувані предмети не повинні стикатися з гравцем і трясти камеру. Скриптові/квестові предмети не гарантовано працюють як звичайний лут.
- Щоб витягти предмет з інвентаря у руку, використовуйте промінь + grip. Для звичайного вибору/перетягування в UI — тригер. Для розряджання почніть тягнути зброю в інвентарі, обшуку або торгівлі й натисніть grip. Остання реалізація всіх трьох вікон потребує повторної перевірки.
- Тип набоїв змінюється **в інвентарі** перетягуванням сумісних набоїв на зброю. Звичайна коробка зі світу або інвентаря не виконує роль активатора перезаряджання.
- Витратний предмет застосовується тригером руки, яка його тримає. Підносити до рота або окремої зони застосування більше не потрібно. Відпущений поза зоною складання предмет можна викинути.
- Інвентар, обшук, торгівля, діалоги й PDA мають класичний вигляд у VR. За ігровими вікнами зберігається стереосвіт. Головне меню та завантаження використовують панель. Усі сторінки PDA, введення тексту та сценарії торгівлі не перевірені повністю.
- На правій кисті — мінікарта, на лівій — штатні показники здоров’я та статусів. Це альфа-реалізація. Стандартний плаский HUD, хотбар і подвоєні підказки прибрані.

## Стрільба та перезаряджання

Автоматична перезарядка порожньої зброї вимкнена. Штатні анімації перезаряджання, взводу, діставання та прибирання вимкнені там, де їх замінює фізична дія. Окремі анімації клину та завершення вставляння заряду залишено навмисно. Відтворюються оригінальні звуки або їх механічні фрагменти.

### Знімні магазини, пістолети, короб ПКМ, батарея Гауса

1. Вільною рукою захопіть магазин біля його гнізда, зніміть і відпустіть.
2. За поясом затисніть вільною рукою **grip + тригер**, щоб дістати новий сумісний магазин.
3. Піднесіть до гнізда, продовжуючи утримувати grip: магазин установлюється при контакті. Відпущений в іншому місці невикористаний новий активатор повертається.
4. Візьміться за затвор/руків’я, повністю відтягніть назад і відпустіть. Гвинтівка Гауса окремого ручного взводу не вимагає.
5. Клин усувається повним рухом затвора; заміна магазину не обов’язкова. Короткого руху недостатньо.

**Обмеження прототипу:** викинутий магазин — тимчасова візуальна модель, а не окремий контейнер набоїв. Залишок повертається у спільний запас, новий магазин витрачає резервні набої при встановленні. Це не симуляція збереження частково заряджених магазинів. Приховування магазину у світовій моделі та всі варіанти зброї ще потребують перевірки.

### Підствольні гранатомети

Утримуйте цівку й натисніть тригер руки додаткового хвату, щоб перемкнутися на гранатомет. За поясом дістаньте сумісну гранату комбінацією перезаряджання та відпустіть біля дула підствола. Завершальна штатна анімація заряджання лишається навмисно. Повторне натискання тригера на цівці або прибирання зброї повертає звичайний режим. Нещодавно виправлені точки вильоту снарядів ще не підтверджені в гарнітурі для всіх моделей.

## Ніж, оптика, пересування

- Ніж завдає шкоди фізичним рухом леза, зі збільшенням шкоди від швидкості; штатної кнопкової атаки немає. Зіткнення гравця з NPC вимкнені для доступу до ближнього бою, але останнє виправлення контактів ще не підтверджене. Реєстрація влучань ножа/куль лишається.
- Бінокль та знімні/вбудовані приціли мають додатковий рендер, сітки й тунельний ефект. Зум бінокля — правим стіком угору/вниз. Додатковий хват підвищує точність; бонус оптики діє лише разом із додатковим хватом і вирівняним поглядом у приціл.
- Увімкнене слабке адаптивне згладжування рук. Кидки й швидкість ножа рахуються за сирою історією руху. Це відстеження контролерів, не голих пальців.
- Фізичний присяд змінює колайдер персонажа. Швидкість зменшується вдвічі, спринт вимикається; останні зміни швидкості та калібрування потребують тесту. Кнопковий присяд у стоячому режимі не потрібен.
- Напрямок звуку слідкує за головою. Виправлення камери допомоги пораненому та сну раніше підтверджені, але всі скриптові сцени не перевірені.

## Графіка та стабільність

Релізні значення взято з **поточного** робочого конфіга розробки: розмір рендера 2560×1440, наявні якість і дальності. Ім’я монітора та конкретну частоту оновлення прибрано для перенесення на інший ПК. Ці налаштування можуть бути вимогливими; за потреби зменшіть їх у грі. Частина параметрів потребує повного перезапуску.

Перед запуском примусово обираються сумісні DX11/R4, вікно без рамки, MSAA off та HDAO off/HBAO. Решта параметрів зберігається. Не вмикайте вручну ексклюзивний fullscreen/MSAA/HDAO у цій альфі: попередня імпортована комбінація спричинила чорний екран і зависання ПК, точну причину не ізольовано. Виправлений запуск підтверджено робочим.

Остання зміна ближньої площини до 5 см спрямована проти мерехтіння перетинів поверхонь. Результат у гарнітурі **ще не перевірений**. Геометрія ближче 5 см може обрізатися; захист лінз адаптовано. Мерехтіння листя може залишатися.

## Що підтверджено

Дивіться [FEATURE-STATUS.uk.md](FEATURE-STATUS.uk.md). «Підтверджено» означає попередній звіт тестувальника на Quest 2, а не проходження всіх перевірок фінальної збірки. Компіляція, тести та розпакування не доводять комфорт у гарнітурі чи можливість пройти всю кампанію.

Пріоритетні перевірки: чиста установка; завантаження після смерті, успішність якого після історичного вильоту прямо не підтверджена; останні зміни перезаряджання, калібрування й лаунчера; перемикач зон; мерехтіння; усі варіанти зброї та довгі сесії.

## Діагностика

- Немає VR: перевірте вхід у USB Quest Link та активне 64-бітне середовище Meta OpenXR. Лаунчер перевіряє реєстрацію середовища, але не готовність самої гарнітури.
- Після меню/втрати трекінгу не працює рух або хват: відпустіть курки, відцентруйте стіки, відновіть відстеження й фокус. Не калібруйтеся в присяді.
- Зони зміщені: станьте рівно та відкалібруйтеся; увімкніть контури в налаштуваннях гри. Оцінювання тулуба може помилятися при незвичній позі.
- Бракує DLL: перевстановіть повний пакет, не копіюйте один `CoPVR.exe`. Вимоги Windows/.NET лишаються.
- Для звіту збережіть `data/logs/`, версію мода, гарнітуру, середовище OpenXR, GPU, назву збереження та точні кроки. За потреби додайте відео/скрін. Перед публікацією перевірте журнали на ім’я Windows і локальні шляхи. Архіви гри не завантажуйте.
- При чорному екрані/зависанні ПК припиніть повторні спроби й повідомте подробиці. Лаунчер не може гарантувати захист від зависання GPU/драйвера.

Лаунчер не має автоматичного завантаження журналів, служби оновлення чи телеметрії. Інсталятор нічого не публікує.
