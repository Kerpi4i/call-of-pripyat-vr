# Стан функцій — кандидат Альфа 0.1.0

Джерело — попередні перевірки на Quest 2 / Touch / USB Link. Історичне підтвердження **не є** регресійним тестом фінальної збірки. Повне проходження та інші гарнітури не перевірялися.

| Функція | Підтвердження та що лишилося |
|---|---|
| Стереосвіт, рух голови, освітлення обох очей | Прямо підтверджено; двоїння/шум і однобічне освітлення на «Скадовську» були виправлені. |
| Наведення Touch, стрільба, вібрація, хвати обома руками, передача, цівка | Раніше підтверджено. Потрібна фінальна перевірка кожної моделі зброї. |
| Вільні кисті, пози ножа/бінокля/детектора | Користувач підтвердив нормальну роботу всіх хватів після виправлень. Не всі варіанти моделей/анімацій перевірені. |
| Піднімання, огляд, передача, кидок; екіпірування світової зброї за рукоятку | Підтверджено. Сила кидка надалі збільшувалася; дальність не виміряна. |
| Промені UI, пропуск логотипів, вихід із завантаження | Підтверджено раніше; нова установка й початок гри потребують перевірки. |
| Стереонакладення інвентаря, діалогів, PDA | Підтверджено раніше. Переходи при закритті та всі сторінки PDA ще треба перевірити. |
| Зони спорядження, ліхтарик за поглядом, сон, рух за головою та звук | Є прямі попередні підтвердження; остання геометрія зон і калібрування потребують регресії. |
| Фізичний присяд зменшує колайдер | Прямо підтверджено. Повне калібрування, зменшення швидкості вдвічі й блок спринту перевірені кодом/збіркою, але не гарнітурою. |
| Стереобінокль, зум, лінзи/тунель/сітки прицілів | Раніше вигляд підтверджено добрим. Після зміни ближньої площини слід перевірити знову. |
| Фізичні магазини, поштучне заряджання дробовиків/РПГ | Група перезаряджань була підтверджена до пізніших уточнень. Потрібна системна перевірка всіх 26 профілів магазинів, семи внутрішніх профілів, точок і звуків. |
| Розряджання в інвентарі | Підтверджено для інвентаря. Пізніша підтримка обшуку/торгівлі прямо не підтверджена. |
| Підствольні гранатомети, заряджання, точки вильоту | Реалізовано; останнє виправлення точок вильоту ще без підтвердження в гарнітурі. |
| РГ-6: засувка, 180°, індексація; SPAS: відкритий затвор для заряджання | Уточнено після відгуків, остаточного підтвердження немає. |
| Усунення клину повним рухом затвора | Реалізовано після звіту користувача; фінальна поведінка не підтверджена. |
| Допоміжний болт разом із довільною зброєю | Додано без повернення зламаної системи незалежних предметів; остання версія не перевірена. |
| Гранати, застосування витратних предметів, хотбар, перетягування типу набоїв | Реалізовано; повний цикл застосування/скасування/витрати потребує регресії. |
| Ящики, тіла, пригнічення колізій предмета з гравцем | Група раніше підтверджена; довільні фізичні й квестові предмети експериментальні. |
| Мінікарта й HUD на кистях, їх перекриття, статуси | Реалізовано та змінювалося; остаточний вигляд/глибина потребують перевірки. |
| Прибирання тіней старого тіла/рук | Кілька виправлень, останнє — фіксація матриць кистей; усі джерела світла не перевірені. |
| Відсутність колізії гравця з NPC | Останнє раннє відсікання контактів не підтверджено; реєстрація влучань навмисно збережена. |
| Графічна сумісність | Виправлений запуск підтверджено після попереднього зависання з чорним екраном. Поточний конфіг використано для релізних значень. |
| Перемикач видимості зон; ближня площина 5 см проти мерехтіння | Лише збірка й кодові/модульні перевірки. У гарнітурі ще не підтверджено. |
| Смерть → завантаження | Раніше повторно вилітало; прямого підтвердження усунення після пізніших змін немає. Пріоритетний тест. |
| Інсталятор, EXE-лаунчер, видалення | Установку й запуск підтверджено власником 2026-10-25; автоматичне розпакування та перевірка комплектності пройшли. Видалення, повторна установка й кожен сценарій UI окремо не підтверджені. |

Не підтримується: автономний Quest/APK, голі руки, повне відстеження тіла, незалежна стрільба з двох вогнепальних одиниць, multiplayer, Enhanced Edition, офіційна інтеграція Steam achievements/cloud saves, Anomaly та глобальні моди. Експеримент незалежних предметів було відкочено через блокування екіпірування. Для детектора є окремі послаблення, а не повна свобода двох незалежних предметів.

Прототипні правила: викинуті магазини — тимчасові моделі зі спільним обліком набоїв; зони використовують оцінювання тулуба. Немає гарантії реалістичної анатомії, фізики кожного квестового предмета, індивідуального запасу в магазинах чи повного проходження.
