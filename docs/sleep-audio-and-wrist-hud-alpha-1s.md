# Sleep, head-relative sound, transparent menus and wrist HUD (alpha 1s)

- Sleep tutorial caption suppression removed. A passive UI mode (frame.menu=3)
  composites its native caption once over the stereo world without disabling
  gameplay Touch controls or drawing UI rays. Main menu/dialogs retain priority.
  Sleep prompt follows head placement; use explicitly dispatches to an active
  tutorial_sleep sequencer so input receiver handoffs do not lose the action.
  Script sleep restrictors and conditions are retained. Bed interaction remains
  fresh index-trigger use with an empty hand.
- SoundProcessor transforms position, forward and up from copvr_get_head into
  world coordinates using the same base camera basis as VR rendering. Listener
  orientation includes head yaw, pitch and roll; native positional sounds use it.
  Two-dimensional music/UI audio retains native behavior.
- Inventory/search menu background statics and autogenerated main background
  panels use flat black alpha 145 instead of stock imagery. Controls, cell icons,
  labels and native drag behavior stay. Shared trade back panels also use tint.
- Dedicated named render targets capture native map/status widgets before UI
  overlay capture. Right dorsal wrist: original zone map with game markers.
  Left dorsal wrist: watch bezel/band, time, numeric HP, health bar and native
  warning/booster icons (bleeding, radiation, hunger, overload, weapon/helmet/
  suit condition, active drug buffs). Captures update once per frame and both
  eye views draw the same surface at tracked wrist poses.
- Wrist UI is hidden when a dialog is open or hand tracking is invalid. Device
  screen offsets and orientation are provisional and need headset checking.
- Body zones now smoothly align with actual horizontal movement velocity above
  .3m/s. When stationary the previously confirmed +/-30 degree torso/head
  deadzone remains. Head weapon/torch zones keep their headset-relative anchors.

Validation: wrist VS/PS compiled with fxc SM5; bridge headless ABI/input/UI-ray/
IK/navigation/grip tests passed. Frame-mode tests include passive sleep overlay
and loading/menu priority; body tests include smooth movement yaw alignment.
No game/OpenXR session test launched. Sleep, audio orientation, menu appearance,
wrist readability/pose and movement ergonomics require user headset testing.

Final validation: Game Release x64 and final xrGame build succeeded; engine patch checks passed.
